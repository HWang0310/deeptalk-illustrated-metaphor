# V0.2 Original Metaphor System Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn B1 Paper Relay into a tested, reusable original metaphor-system prototype and produce V0.2 comparative deterministic evidence.

**Architecture:** A new vocabulary module defines immutable case-level `MetaphorSpec` data and SVG object rendering. `art.py` delegates the V0.2 B1 track to that layer while legacy comparators remain unchanged. The runner includes the new track in its narrow corpus and passes structural visual metadata to QA.

**Tech Stack:** Python standard library, SVG, macOS `sips`, FFmpeg, unittest.

**Spec:** `docs/plans/2026-08-28-v0.2-original-metaphor-system-design.md`

## Global Constraints

- Track A is frozen reference-only and remains marked `upstream-reference-only`.
- Track B is original research, not a mascot or formal brand identity.
- Chinese stays in deterministic SVG typography.
- Approved-still deterministic motion remains the delivery baseline.
- No DeepTalk Core changes and no final integration contract.
