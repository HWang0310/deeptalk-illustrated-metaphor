# V0.2 Original Metaphor System Design

## Decision context

V0.1 passed the transferable illustrated-metaphor hypothesis. Track A remains a frozen, attribution-labelled upstream reference; it receives no new production capability. B1 Paper Relay is the primary research baseline, but is still an original visual-language hypothesis rather than a brand, mascot, or fixed character IP. B2 Object Theatre stays as an actor-free comparator.

## Chosen approach

V0.2 replaces B1's rendering-only case conditionals with a declarative metaphor-system layer. Each of the unchanged seven benchmark IDs owns a compact `MetaphorSpec`: actor role, original objects, spatial relation, focal object, annotation position, state-change rule, and motion opportunity. The SVG renderer consumes that specification and preserves deterministic Chinese typography.

This is preferable to treating B1 as a generic paper style because it makes the cognitive claim, visual vocabulary, and QA criteria inspectable. It is intentionally narrower than a general scene graph or an integration contract.

## Original B1 vocabulary and grammar

The vocabulary is limited to original cut-paper primitives with charcoal outline, cobalt structural planes, coral action planes, pale-green state/load objects, and warm-white field: load/weight, barrier, bridge, container, stack, rope/tension, wheel/loop, threshold, crack, network node, path, gate, resource block, and signal card. They are composable only in a 16:9 editorial card with one focal object and sparse deterministic annotation.

| Benchmark | Actor role | Object / relation | Focal / state change | Annotation and motion opportunity |
| --- | --- | --- | --- | --- |
| burden growth | bearer | load expands in front of actor | load; scale and weight increase | upper-left label; load emphasis |
| tug of war | counter-force | two actors or force blocks pull one rope | rope midpoint; opposing displacement | upper-left label; tension pulse |
| speed loop | runner | actor adjacent to wheel/path | wheel; loop radius and arrow accelerate | upper-left label; rotational focal push |
| hidden fragility | observer | bridge/platform crosses a crack | crack; concealed crack becomes visible | upper-left label; crack reveal |
| information overload | receiver | signal cards overflow a container | container mouth; cards accumulate | upper-left label; staged card reveal |
| network effect | optional / object-only | node propagates through connected nodes | origin node; connected nodes activate | upper-left label; propagation cut |
| state transition | chooser | actor crosses a threshold/gate onto path | gate; actor/path moves from reactive to active | upper-left label; gate/path reveal |

The generic actor remains an anonymous shape grammar. It has no face, name, personality, fixed identity, or claim to a DeepTalk-owned character. Object-only is deliberately used where agency would obscure a system relationship.

## Deterministic motion

Approved-still output stays a 3–10 second, single-approved-still baseline with fade, bounded focal push, and hold. V0.2 makes the focal-object intent explicit in the route metadata, but does not claim separate object animation from a single source frame. Structured-state hybrid is rendered only for burden growth, information overload, and state transition, where a temporal change is central to comprehension. Independent keyframes remain frozen.

## QA and evidence

The V0.2 renderer records the case specification beside each asset. QA validates: recognised focal object, bounded object count, sparse annotation count, explicit actor/object separation when an actor is used, non-empty final state, duration, files, provenance, and ordered states. These are structural readability guards, not automated aesthetic judgment.

The comparison corpus preserves all seven benchmark cases and renders Track A reference, B1 V0.1 baseline, B1 V0.2 system, and B2 Object Theatre in approved-still form (28 assets), plus three V0.2 structured-state assets (31 total). Repeating the corpus verifies deterministic sequence hashes. Existing two-state model evidence is retained; no further model expansion is justified until it can lock layout and proportion.

## Constraints and decision rule

- Do not modify DeepTalk Core or define a final plugin contract.
- Do not copy upstream Xiaohei assets/code or claim Xiaohei / 小黑 as project IP.
- Keep Chinese in deterministic SVG/PingFang, not image-model output.
- Do not promote B1 to formal brand identity or a mascot.

V0.2 can recommend B1 as the current *research* baseline only if each benchmark has distinct object/space grammar, deterministic assets remain repeatable, and the actor offers clearer causal agency than actor-free B2 without becoming a fixed character. Structured state is recommended only where its extra state information materially clarifies the semantic claim.
