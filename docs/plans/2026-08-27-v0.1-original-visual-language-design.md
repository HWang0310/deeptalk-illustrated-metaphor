# V0.1 Original Visual Language Design

## Decision context

V0 passed the method-level hypothesis: illustrated/character metaphor can work without claiming the Xiaohei identity. Track A is now frozen as a provenance-labeled reference comparator. Track B is the primary R&D track, but no candidate becomes a DeepTalk brand identity in this phase.

## Hypotheses

### B1 — Paper Relay (generic actor)

An anonymous, reconfigurable cut-paper figure makes physical effort and state change immediately legible without becoming a mascot. It uses off-white ground, cobalt body planes, coral joints/actions, pale-green burden/state objects, and charcoal outlines. The actor has no name, face, fixed proportions, or personality; it is a compositional device rather than an IP.

### B2 — Object Theatre (no actor)

Tactile geometric objects and a small stage can carry the cognitive action without a recurring character. It uses a warm-white field, charcoal structural outline, indigo/coral/yellow object roles, sparse labels, and conspicuous negative space. This tests whether editorial metaphor can retain clarity while avoiding character consistency cost.

## Metaphor grammar

- One semantic claim per frame.
- Represent the claim as one physical constraint, transfer, imbalance, accumulation, or release.
- Use a single focal object and one secondary object at most.
- Keep Chinese outside model-generated imagery and overlay it deterministically with SVG/PingFang.
- Preserve a stable 16:9 editorial frame with at least one quiet region for spoken-video compositing.

## Motion system

Approved-still motion remains the delivery baseline: lead-in reveal, bounded focal shift, object emphasis, then a readable hold. Structured scene-state hybrid is retained only as a 2–3-state value study. Independent keyframes remain a frozen high-risk comparator.

## Study design

Use the existing seven semantic benchmark cases. Compare Track A reference, Track B V0 neutral, B1, and B2 on metaphor clarity, annotation space, state readability, motion compatibility, and production risk. Run one small two-state model generation study for B1 only, with a locked character/object description and no in-image text. It tests consistency; it is not a production pipeline.

## Expected decision rule

Recommend a current Track B baseline only if one candidate is clearly more coherent across the benchmark and compatible with the deterministic motion system. Recommend a fixed original character only if it materially improves clarity/continuity more than it increases identity and consistency cost. Do not make a branding claim.
