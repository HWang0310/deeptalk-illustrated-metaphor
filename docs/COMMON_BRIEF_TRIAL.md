# Cross-Plugin Common Brief Trial — Illustrated Metaphor Track

## Scope

This is an Illustrated Metaphor-only comparison experiment, not V0.3 or a Plugin Contract. It used the exact eight Common Brief semantic tasks supplied for the trial. No MG or Hand-drawn trial repository, asset, output, or result was opened or inspected. Track A remained frozen and no Track A Common Brief asset was generated.

## Family capability finding

Illustrated Metaphor is most natural for one physical constraint or state relationship: accumulation and load, opposing agency, feedback/momentum, visible-versus-hidden fragility, and threshold/state changes. The generic actor improves effort, responsibility, choice, and tension; object-only is preferred when an actor would falsely imply agency, as in CB02 transmission.

It is less natural for exact numeric evidence, dense causal chains, and narrow conditional judgments that must preserve business-specific logical distinctions. Sparse Chinese copy can name a mechanism but should not be used to conceal that the image itself is underspecified. CB08 is therefore a positive abstention, not a failed render.

B2 Object Theatre was considered but not used: no brief was more naturally expressed by its current generic stage than by B1's existing object-only network or actor grammar. This is not evidence that B2 has no value; only that it did not provide a clearly better candidate in this fixed trial.
