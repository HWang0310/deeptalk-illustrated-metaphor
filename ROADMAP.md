# Roadmap

## V0 — Evidence-first R&D

- Audit upstream Xiaohei repository and capture provenance boundaries.
- Define dual-track cognitive-metaphor benchmark.
- Build no-key deterministic still-to-motion baseline and two comparison routes.
- Render short assets, contact sheets, manifests, and QA evidence.
- Decide whether the useful value is identity-specific or method-level.

## Later, only after evidence

- Evaluate original character language candidates.
- Evaluate image-generation adapters without making user API keys a V0 requirement.
- Consider a DeepTalk integration contract only after this plugin has stable natural inputs and outputs.
